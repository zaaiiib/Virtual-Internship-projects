# Thiranex Virtual Internship Projects

This repository serves as a centralized hub for all projects, assignments, and practical tasks completed during my virtual internship program with **Thiranex**. It highlights hands-on experience in modern web development, emphasizing clean code architecture, performance optimization, and industry standards.

## 📂 Projects Included

* **Accessible Portfolio Skeleton**
  * **Overview:** A fully semantic, screen-reader friendly portfolio template built to achieve a 100% score on Lighthouse Accessibility and SEO audits.
  * **Key Features:** 
    * Utilization of proper semantic HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
    * Custom ARIA roles, attributes, and labels for enhanced assistive technology support.
    * Keyboard navigation features including skip links and high-visibility focus states.
    * An accessible contact form with explicit label-to-input associations.
